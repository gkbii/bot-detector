Bot Detector

Badges Reddit commenters with automation and agenda signals as you scroll, and shows the working behind every band.

Scanning

Where scoring happens

Current mode: local

Leave this empty and everything runs in your browser: the extension fetches the public Reddit archive directly and scores it locally. No account, no API key, no server, and nothing about your browsing leaves the machine except the username being looked up.

Set it and lookups go to your own server instead, which can add an LLM read of an account's agenda — the one part that needs an API key, and therefore the one part that cannot live inside an extension anyone can unzip. If a configured backend is unreachable, scoring falls back to local and every card says so rather than quietly pretending.

Cache

Verdicts are cached in this browser for 12 hours, capped at 300 accounts with least-recently-seen eviction. Scrolling past the same person twice is one lookup — the archive is a free public service and this extension is not going to be the reason it stops being one.

What this extension can see, and why

storage Your settings and the verdict cache. Nothing is uploaded from it.
*://*.reddit.com/* Reads the Reddit pages you are already looking at, to find usernames. This is the content script's match pattern only — the extension's background worker has no permission to fetch reddit.com at all.
arctic-shift.photon-reddit.com The public archive of Reddit comments and posts that the scoring is based on. The only host this extension ever contacts, and only ever with a username.
Your backend, if you set one Requested when you save the URL, not at install — and revoked whenever you clear the field.

Not requested: access to your tabs, your history, your cookies, or any site other than the two above. No telemetry, no analytics, no remote code. Everything that runs is in this folder.
