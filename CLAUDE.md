# bot-detector

Reddit account signal analysis: three separate scores, no blended number. The
Chrome extension is the product; the Node server is optional.

**The one PUBLIC repo.** It installs and runs on a laptop that has never heard
of the machine it was written on: no control-plane bootstrap, no shared secret,
nothing outside this tree. `bb doctor --public` asserts it.

## Where things are

| Path | Owns |
| --- | --- |
| `extension/` | The product. MV3, load-unpacked, no build step. Must stay copy-out-able. |
| `extension/lib/sources/` | The only modules that know an archive's URLs. |
| `extension/lib/scoring/` | `scoreAccount()` — pure function, three axes. |
| `extension/errors.js` | The ONE error taxonomy, shared by both halves. |
| `extension/log.js` | `log(domain, event, fields)`. `docs/architecture.md` has the tree. |
| `server/` | The optional backend: a Claude read and a shared cache. Nothing else. |
| `server/registry/` | ENV, ROUTES, EVENTS. Load-bearing, not documentation. |
| `docs/registry.md`, `.env.example` | Generated by `npm run registry`. Never hand-edit. |
| `docs/decisions/` | One file per decision still in force and not testable. |
| `docs/evaluating.md` | The measurement harness and the hand-run scripts. |
| `EVALUATION.md` | What it scored against live accounts, and every defect found since. |
| `scripts/` | Not shipped, not imported, not run by `npm test`. |

`README.md` is install and use only. Rationale goes to `docs/decisions/`, never
to the README, and no document gets a per-ticket section or a dated changelog
entry — the commit message carries that.

## Invariants

**Never treat a passing suite as evidence it works.** Every defect that mattered
was found against live accounts, not by the green tests running at the time. A
shallow comment window merged with one ancient post forged a 12-year dormancy
signal out of our own pagination; `fetchImpl` unbound passed all 106 tests and
threw `Illegal invocation` in the real service worker. A change to the fetch
window, the pagination, or any timing signal gets a live run.

**`extension/lib/**` cannot become `.ts`.** Browsers do not strip types, and the
worker imports those files directly. See `docs/decisions/0011`.

**No `throw new Error` in `extension/` or `server/`** — every throw is a coded
class from `extension/errors.js`. `test/conformance.test.cjs` asserts it.

**A registry is not documentation.** `config.ts` reads through `registry/env.ts`
and nothing else; `index.ts` dispatches through `registry/routes.ts`.
`test/registry.test.js` ties each entry back to the code it describes.

**Every bound that fires says so out loud** — a cap, a truncation, a skipped
item, a withheld verdict. A run that quietly covered 12 of 20 accounts is worse
than one that admits it. The grey "no data" badge is a real verdict, not a
failure.

**Citations are verified, never trusted.** A cite that does not resolve against
the evidence pack is dropped and reported; a finding whose citations all fail is
rejected. The model is never asked who an account belongs to, and the schema
gives it nowhere to put such a claim.

**Absence of evidence is not evidence.** An unmeasurable signal is excluded from
an axis average, never counted as a clean zero.

**The suite runs with no `node_modules`.** Keep it that way: the one dependency
is imported lazily inside `getClient()`, and the typechecker comes from `npx`
(`docs/decisions/0012`).

**`docs/size-exceptions.json` holds only paths** — the conformance template
joins every key to the repo root, so a `//` comment key crashes it (`EISDIR`).

## Commands

```sh
npm test        # typecheck + both suites (200 tests), no install needed
npm start       # the optional server
npm run registry    # re-render docs/registry.md and .env.example
npm run evaluate    # the band table, off the frozen corpus in test/corpus/
```

`npm run measure:*` are the hand-run measurements behind `EVALUATION.md`. Five
go to the network; none is part of `npm test`. `docs/evaluating.md` says which.
